# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, insults, discrimination or sexualized language, in any project space (issues, pull requests, discussions).
- Assume good intent and help newcomers.

Maintainers may edit or remove contributions and block participants who do not follow these rules.

To report a problem privately, use GitHub's private reporting form (**Security → Report a vulnerability**) and mention that it is a conduct report. Reports are handled confidentially.
